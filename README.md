### 🚀 Projeto em destaque

#### [Distribuidora Sousa — Sistema de estoque e balcão](https://github.com/juan1992tj1-prog/distribuidora-sousa)

▶ **[Abrir a demo online](https://distribuidora-sousa.vercel.app)** (dados fictícios, entra com um clique) · 🌐 **[Meu portfólio](https://juan1992tj1-prog.github.io)**

Sistema web completo para uma distribuidora de bebidas, feito para rodar num mini-PC dentro da loja.

- 📦 Estoque por **lote e validade (FEFO)**: sai primeiro o que vence primeiro, vencido nunca é vendido
- 🧾 Importação do **XML da NF-e** do fornecedor com **conferência cega**
- 🛒 **PDV** com leitor de código de barras/QR (EAN, GS1, DataMatrix), troco, Pix, cartão e fiado
- 💰 **Caixa** com abertura, sangria e **fechamento cego** (esperado × contado)
- 📈 Painel com curva ABC, alertas de vencimento e **sugestão de compra** pelo giro
- 🤖 **Leitura de nota com IA** (API do Claude): PDF ou foto do DANFE vira lista de itens validada para a conferência cega
- ✅ Regras de negócio cobertas por **testes automatizados** em PostgreSQL em memória

`Next.js` · `TypeScript` · `PostgreSQL` · `Drizzle ORM` · `Tailwind` · `Docker` · `Vitest` · `Claude API`
